Data Processing
===============

Overview
--------

NYX has 2 data processing pipelines that will run on all samples.

The first pipeline uses `fast_dp <https://github.com/DiamondLightSource/fast_dp>`_. This should return a result within a minute of data collection. Results will be available
in the 'Processing' tab of nyx-gui. If a result does not appear within a few minutes, it is likely that the pipeline failed.
If processing succeeds, the results will be available in the 'fast_dp_dir' directory in the root folder of the data collection directory.
All the files generated by the fast_dp run will be in the 'fastDPOutput' directory in the data directory that the data
was collected in.

The second pipeline uses `autoPROC <https://www.globalphasing.com/autoproc/manual/index.html>`_. This will only be
available to academic users and members of the Global Phasing Consortium. This can take from 5 - 20+ minutes to complete
depending on cell parameters. Results will be available in the 'autoproc_dir' directory in the root folder of the data
collection directory. All the files generated by the autoPROC run will be in the 'autoPROCOutput' directory in the data
directory that the data was collected in.


Software Options
----------------

The following software packages are available for processing data collected at NYX:

* `XDS <https://www.dectris.com/en/detectors/XDS/>`_
* `DIALS <https://dials.github.io/>`_
* `xia2 <https://xia2.github.io/>`_
* `fast_dp <https://github.com/DiamondLightSource/fast_dp>`_
* `autoPROC <https://www.globalphasing.com/autoproc/manual/index.html>`_
* `HKL2000 <http://www.hkl-xray.com/hkl-2000-manual>`_
